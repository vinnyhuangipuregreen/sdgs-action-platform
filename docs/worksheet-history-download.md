# 練習單歷史紀錄與 Word 下載

歷史紀錄視窗最大寬度 1280px，列表各欄位與操作按鈕維持單行；視窗較窄時僅列表內水平捲動。

歷史紀錄的「下載Word」使用既有授權端點 `/api/worksheets/{id}/export-docx?format=doc`，產生 Word 可開啟的 RTF 相容 `.doc` 文件，並非將 DOCX 的 ZIP 內容直接改名。內容沿用既有 DOCX 產生器，保留段落、粗體、表格與中文；未變更練習單資料庫或權限判斷。其他既有匯出呼叫未指定 format 時仍為真正的 DOCX。

伺服器以該份練習單的 user_name 和下載當下臺灣時間產生 Content-Disposition 檔名：`連動分析練習單_學員姓名_YYYYMMDDHHmmss.doc`。前端採用此檔名，直接下載備援也保留相同格式參數。

本機七種尺寸（1920、1440、1366、1280、1024、768、390px）驗證所有欄位為 nowrap、頁面無水平溢位。實際瀏覽器下載符合命名格式。隔離樣本使用 Microsoft Word 開啟 `.doc`，辨識五個表格並匯出兩頁 PDF，已確認中文、活動成果與因果分析內容可讀。新增後端與前端測試涵蓋檔名、格式、權限及備援下載；既有 DOCX 測試保留。
